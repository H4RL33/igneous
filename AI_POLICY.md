# AI Policy & Disclosure

Igneous has been built by a human maintainer using AI as a development tool, as it is intended to be.

- Large parts of Igneous' codebase was written by Claude Opus 5.5 via Claude Code following my direction.
- I decide what features Igneous should have, Claude proposes it's work which I review.
- Following my direction, Claude runs extensive testing on Igneous, and visually analyses screenshots for GUI correctness.
- Igneous itself contains no AI features and never will.

Furthermore, I have personally tested Igneous against a real-world pre-existing Obsidian vault I have, several bugs, freezes, and crashes have been discovered and fixed this way. This process continues as I use Igneous daily.

All usage documentation, project documentation, and artwork has been done by humans, except for the building instructions on the README as Claude simply has more context about that than I do and thus provides better instructions.
